C4: Value Grounder — linking entity mentions and filters to actual database values.

Source: [`value_grounder.py`](../../../../src/datamate/grounding/value_grounder.py)

## Trách nhiệm và luồng dữ liệu

Module C1–C5 legacy, giữ cho modes rules/hybrid và các caller hiện hữu. NeoGroundingEngine không gọi module này trực tiếp; không dùng kết quả heuristic để nâng trust của contract v2.

## Interface

- `ValueGrounder`: Link Vietnamese entity phrases and filter values to real database values.
